# 发布说明 / Release notes

## V3.0.0 — 2026-10-23

### 中文

- 统一 R0–R6：九模块参考解析、单项目品牌转译、文字/草图蓝图、视觉生产、核验、最小修复冻结、PNG/ORA 交付。
- 项目状态保存要求来源、采用/改写/舍弃、范围与替代关系，阻止过期或已舍弃要求进入制作。
- 四类生产任务绑定当前蓝图、实际附件、基准、提示与文件校验值；内置负面约束进入实际提示。
- 连续修改保留父子版本、工作版和接受版；局部硬锁、原件层替换与复用生成结果的合成修复限制额外变化。
- 接通真实检测、独立视觉观察、缺陷复核、用户决定与母版冻结；本地工作台的生产按钮只排队。
- PNG/ORA 重读并重组对比母版；旧项目显式迁移，旧批准不自动导入。
- 验证：54 项新流程测试、70 项独立兼容测试，一个 4 次调用的受控分层实图闭环。范围外像素保护不代替语义与接缝核验。

### English

- Unified R0–R6: nine-module reference analysis, project brand translation, text/sketch blueprint, production, verification, minimal repair/freeze, and PNG/ORA delivery.
- Authoritative project records track requirement provenance, adoption/adaptation/rejection, scope, and supersession, blocking stale or discarded requirements.
- Four production task types bind the current blueprint, actual ordered attachments, baseline, prompt, and file hashes. Built-in negative constraints enter the real prompt.
- Successive revisions retain ancestry and separate working/accepted versions. Local hard locking, original-layer replacement, and recomposition from existing generation output limit unintended changes.
- Real machine checks, separate visual observations, defect review, user decisions, and master freezing are connected. Workbench production buttons only queue tasks.
- PNG/ORA readback and recomposition are checked against the master. Explicit legacy migration does not import old approvals.
- Validation: 54 new-workflow tests, 70 isolated compatibility tests, and one controlled four-invocation layered image loop. Pixel preservation does not replace semantic or seam review.

See [README.md](README.md), [README.en.md](README.en.md), and [VALIDATION.md](VALIDATION.md) for installation, workflow, deliverables, and validation limits.
