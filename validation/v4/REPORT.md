# V4 通用化候选验证

日期：2026-11-06。生产基线：14daf4fc。V4 不是正式发布；原 V3.1 全局安装与 QC 不修改。

## 实现范围

- cvisual.workflow.v4 状态隔离，复用 R0–R6、准确原件、硬锁补丁、PhotoCraft 和审核放行逻辑。
- model_policy=latest：从官方日期发布记录解析，不按模型名称数字排序；记录来源和哈希，执行前重新抓取；未知代适配、陈旧目录、能力不符和内置型号不透明均阻断。
- OpenAI Images 生成／编辑和 Google 原生 Interactions 请求／响应契约。纯标准库 HTTP，不引入 SDK 默认重试；只处理单张最终 PNG。
- 项目外共享预算、单执行端、未知结果保守预留；费用依据是执行者有来源的上界判断，不是精确账单报价。开发默认额度 0。
- 项目移交、安全解包、逐项校验、待执行任务重编译；V3 导入独立新目录，历史证据和未知型号保留，批准不导入。
- native、Codex、Claude Code、Cursor 四种结构包，共享同一文件清单；聊天平台是否实际接受需独立验证。

## 测试身份与范围

V4 内的原 117 项流程用例是复用后的 V4 状态回归；新增适配／目录／预算／迁移／HTTP 测试明确使用合成夹具。V3 117 与 V2 70 仍从原目录在独立进程运行。实际数量与退出状态取本提交生成的三份日志，不能用旧运行代替。

本轮 Windows 10 19045／Python 3.12.14／Pillow 13.0.0／NumPy 2.3.5／无 SciPy 实际结果：V3 117、V2 70、V4 173 项均通过。V4 含 117 项复用流程回归与 56 项新增测试。四种候选包各 50 个核心文件逐项一致，实际解包后的初始化默认 0 次，native 安装副本的 24 项模拟生图测试通过；这不代替宿主自动发现或账户导入。

本轮实际读取 OpenAI 与 Google 官方发布记录，不调用图像服务。Google 文档同时提及新型号、被替代型号和弃用型号；初次解析把后两者带入候选，已留存失败并收紧为独立发布段落，另测“an update to”历史提及。新型号尚未覆盖参数契约时仍阻断。

## 未完成与已知限制

- 真实生图 0；当前执行进程没有 OPENAI_API_KEY／GEMINI_API_KEY。接口模拟通过不是账户权限或模型图像质量通过。
- 本轮只做宿主环境盘点与隔离安装副本脚本冒烟。CLI 可见、技能包结构正确，不代表宿主自动发现或端到端调用已测。Claude Code／Cursor 及 ChatGPT／Claude／Gemini 聊天账户实际调用仍须逐项验证。
- PhotoCraft 真实证据仍属于 V3.1，V4 本轮没有重跑引擎。其机器门槛保留；GUI、复杂混合、活文字和跨会话撤销仍未测。
- Google 首版只开放已有明确契约的 1024×1024／1:1／1K 静态图，未验证透明输出，不能自动抠图或缩放以冒充支持。
- 新代模型需新增参数契约审查；latest 解析不保证新代立刻可生产。网络／官方文档格式变化导致未知时阻断，不回退。
- 只支持可共享同一预算文件的单端执行资格移交；没有多端离线额度或新云桥接。
- V3 迁移为完整归档＋未绑定新状态，须重新建立有效来源与 R0–R2，不是历史任务的一键继续。
- 本地决定与恢复证据是声明式记录，不是服务商签名或用户身份认证。原始服务记录、原图及人工目标观察仍有必要。

## 复现

在仓库运行 `python tools/run_validation.py --out <新证据目录>`，保存 v3.log、v2.log、v4.log、环境信息和源清单。原约定六环境会运行同一入口；只有实际日志与源清单匹配才记录通过。

`python tools/package_v4.py --out <项目外目录>` 生成四种安装结构并逐项对照哈希。实际安装副本还须运行 workflow 初始化、零额度检查及相应冒烟；不覆盖全局生产技能。

最终提交、CI、文件清单和安装副本实际结果由本轮评审包给出。本轮不合并、不发布标签。原 PR #1 已被远程合并，本次使用独立 V4 草稿 PR；不改写其历史身份。
